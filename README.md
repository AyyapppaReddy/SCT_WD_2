# StartNStop — Precision Stopwatch ⏱️

A browser-based stopwatch application built with HTML, CSS, and JavaScript. It provides start, pause, reset, and lap functionality with a responsive interface.

## Features

- Start and pause timing
- Reset the stopwatch
- Record lap times
- Millisecond display
- Responsive interface
- Accessible button labels

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Tailwind CSS CDN

## Run Locally

```bash
git clone https://github.com/AyyapppaReddy/SCT_WD_2.git
cd SCT_WD_2
```

Open `index.html` in a modern browser.

## Project Goal

The project demonstrates DOM manipulation, timer logic, event handling, UI state management, and responsive front-end development.
